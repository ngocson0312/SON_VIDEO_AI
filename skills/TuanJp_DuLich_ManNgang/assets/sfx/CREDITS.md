# Nguồn SFX

Chép từ thư viện SFX có sẵn của dự án SON_AI_VIDEO (`DUNG-TOI/assets/sound-effects`, skill `skill_video_bds_bietthu`,
`minh-tam-edit`) — sưu tầm nhiều năm, KHÔNG ghi lại giấy phép từng file (whoosh-short.mp3 gốc Pixabay).

Không khuyến khích dùng cho video thương mại. Làm thương mại / phát hành template: thay bằng SFX CC0 hoặc đã mua
giấy phép, GIỮ NGUYÊN tên file (code gọi theo tên trong `scripts/chung.py` → `SFX_NHOM`).

`jet-flyby.wav`, `xe-chay.wav`, `song-nuoc.wav` (đồ hoạ hành trình) do skill TỰ TỔNG HỢP bằng `scripts/tao_sfx_ht.py`
(ồn lọc + sóng hài, không lấy mẫu từ đâu) — dùng tự do, chạy lại script là tạo lại được.

`boom.wav` (cú drop tên chủ đề) do skill TỰ TỔNG HỢP bằng `scripts/tao_sfx.py` (sóng sin quét 110 → 38 Hz + hài bậc 3 + ồn lọc 150–500 Hz) — dùng tự do.
