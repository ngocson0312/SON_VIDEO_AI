--------------------------------------------------------------------------------
Mở PowerShell hoặc CMD, chạy lần lượt (hoặc tải tay từ trang chủ):

   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   winget install OpenJS.NodeJS.LTS

 - Python 3.10 trở lên (python.org — khi cài nhớ TICK "Add python.exe to PATH").
 - FFmpeg bản FULL (gyan.dev hoặc lệnh winget ở trên).
 - Node.js 22 trở lên.
 - Google Chrome hoặc Microsoft Edge (Edge có sẵn trong Windows) — dùng để dựng hình.
 - Claude Code (app Claude desktop, tab Code; hoặc bản dòng lệnh) — để ra lệnh dựng video bằng tiếng Việt.

Cài xong ĐÓNG hết cửa sổ lệnh rồi mở lại (để máy nhận PATH mới).
