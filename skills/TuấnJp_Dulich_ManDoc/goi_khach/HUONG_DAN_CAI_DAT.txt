BỘ DỰNG VIDEO DU LỊCH DỌC 9:16 — skill TuấnJp_Dulich_ManDoc (bản 13/11/2026)
================================================================================

Gói này gồm:
  .claude\skills\TuấnJp_Dulich_ManDoc\   skill (code, font, SFX, khung đồ hoạ, mẫu kế hoạch)
  CLAUDE.md / AGENTS.md                   chỉ dẫn cho trợ lý AI (Claude Code / Codex) — đừng xoá
  CAI_DAT.bat                             nháy đúp để cài thư viện + kiểm máy
  HUONG_DAN_CAI_DAT.txt                   file này

Resources từng video (giọng đọc, clip, ảnh, nhạc nền) anh/chị tự chuẩn bị — xem mục 4.


1. CÀI PHẦN MỀM (1 lần trên mỗi máy, Windows 10/11)
--------------------------------------------------------------------------------
Mở PowerShell hoặc CMD, chạy lần lượt (hoặc tải tay từ trang chủ):

   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   winget install OpenJS.NodeJS.LTS

 - Python 3.10 trở lên (python.org — khi cài nhớ TICK "Add python.exe to PATH").
 - FFmpeg bản FULL (gyan.dev hoặc lệnh winget ở trên).
 - Node.js 22 trở lên.
 - Google Chrome hoặc Microsoft Edge (Edge có sẵn trong Windows).
 - Claude Code (app Claude desktop, tab Code; hoặc bản dòng lệnh) — để ra lệnh dựng video bằng tiếng Việt.

Cài xong ĐÓNG hết cửa sổ lệnh rồi mở lại (để máy nhận PATH mới).


2. GIẢI NÉN + CÀI THƯ VIỆN
--------------------------------------------------------------------------------
 a) Giải nén file zip ra 1 thư mục đường dẫn NGẮN, ví dụ  D:\VideoDuLich
    (nên giải nén bằng Windows hoặc 7-Zip; tên thư mục skill phải đúng là "TuấnJp_Dulich_ManDoc" có dấu).
 b) Nháy đúp CAI_DAT.bat  → tự cài thư viện Python (cần mạng, vài phút) và kiểm ffmpeg / Node / Chrome.
    Phải thấy dòng:   CÀI ĐẶT: SẴN SÀNG ✅
    Còn dòng ⛔ thì làm theo hướng dẫn ngay dòng đó rồi chạy lại CAI_DAT.bat.
 c) (Tuỳ chọn) tải sẵn mô hình nhận giọng nói Whisper (~3 GB) để lần đầu làm video khỏi chờ:
    mở CMD trong thư mục giải nén, chạy:   CAI_DAT.bat --tai-mo-hinh
    Không tải trước thì lần làm video đầu tiên tự tải.


3. LÀM VIDEO
--------------------------------------------------------------------------------
 a) Mở THƯ MỤC GIẢI NÉN trong Claude Code (thư mục có file CLAUDE.md).
 b) Gõ yêu cầu, ví dụ:

    Làm video du lịch từ link https://vietnamtourism.gov.vn/post/67596
    + audio D:\Khach\HaNoi\Giong_doc.mp3 + Resources D:\Khach\HaNoi\Resources

    (không có bài báo thì bỏ phần link; muốn chữ trên hình tiếng khác thì nói thêm, vd "giọng Việt, sub tiếng Hàn")
 c) Trợ lý tự nghe lời, ghép cảnh, làm đồ hoạ, rồi DỪNG 1 lần ở CỔNG DUYỆT để hỏi:
    tên kênh hiện ở cuối video, giữ / đổi nhạc nền, chữ nút theo dõi… — trả lời là nó dựng tiếp.
 d) Kết quả: file  <tên file giọng>_DLV.mp4  nằm cạnh file giọng (làm lại thì _DLV_ban2, _ban3… không ghi đè).
    Dựng ~2 phút video mất khoảng 4–6 phút (tuỳ máy).


4. CHUẨN BỊ RESOURCES CHO MỖI VIDEO
--------------------------------------------------------------------------------
 - 1 file GIỌNG ĐỌC: .mp3 / .m4a / .wav (tiếng gì cũng được — chữ trên hình tự theo tiếng đó).
 - 1 thư mục RESOURCES gồm:
     • clip (.mp4 / .mov…, quay dọc càng tốt) và ảnh (.jpg / .png / .heic…);
     • ĐẶT TÊN FILE THEO ĐÚNG TÊN ĐƯỢC ĐỌC trong giọng để tự khớp đúng giây, ví dụ:
         "Phở bò.jpg", "Bún chả.jpeg", "sân bay nội bài.jpg", "Hồ_Gươm.mp4", "Video_máybay.mp4"
     • 1 file NHẠC NỀN (vd Music_Bg.mp3) — có thì tự ghép dưới giọng, không có thì thôi.
 - Câu đọc có di chuyển ("bay 4 tiếng rưỡi từ Incheon tới Nội Bài", "đi ô tô 27 km", "cách 2,5 km") tự thành
   hành trình trên BẢN ĐỒ VỆ TINH THẬT; có ảnh điểm đi / điểm đến (vd ảnh sân bay) thì được gắn lên ghim.
 - Link bài báo du lịch (tuỳ chọn): lấy thêm ảnh + số liệu.


5. CẦN MẠNG KHI LÀM VIDEO
--------------------------------------------------------------------------------
Lấy bài báo, ảnh vệ tinh (Esri), đường đi thật (OSRM), toạ độ địa điểm (OpenStreetMap), lần đầu tải Whisper.
Ảnh vệ tinh đã tải được giữ ở thư mục _cache_tiles (đừng xoá — lần sau nhanh hơn).


6. LỖI HAY GẶP
--------------------------------------------------------------------------------
 - "python không phải lệnh…"      → cài lại Python, TICK "Add python.exe to PATH", mở lại cửa sổ lệnh.
 - "thiếu ffmpeg" / "thiếu Node"   → cài theo mục 1, mở lại cửa sổ lệnh, chạy lại CAI_DAT.bat.
 - "Không tìm thấy Chrome / Edge"  → cài Chrome, hoặc đặt biến môi trường DLV_CHROME=<đường dẫn chrome.exe>.
 - Lần đầu nhận giọng rất lâu      → đang tải / chạy Whisper bằng CPU, cứ để chạy.
 - Tên thư mục skill bị lỗi font sau khi giải nén → giải nén lại bằng 7-Zip.

Ghi chú bản quyền: font trong assets\fonts theo giấy phép SIL OFL (file OFL*.txt kèm theo).
SFX trong assets\sfx: xem assets\sfx\CREDITS.md — làm video thương mại nên thay bằng SFX có giấy phép (giữ nguyên tên file).
